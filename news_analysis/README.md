# Анализ новости для компании

Django-приложение `news_analysis`: для пары «новость × компания» три агента готовят персональный разбор — почему новость важна именно этой компании, риски, возможности, действия и позицию Альфа-Банка. У каждого вывода есть ссылки на источники.

Подбор новостей и оценка релевантности для ленты, чат и парсер — в других модулях. Здесь только анализ одной заданной пары.

## Как устроено

```
prepare ── текст статьи: из входа (content) или загрузка по ссылке; иначе работаем по анонсу
   │
news_analyst ── агент 1 (Gemma 4): факты F…, каналы влияния C…, комментарии Альфа-Банка Q…,
   │            запросы к аналитике банка. Один раз на новость, кэшируется в базе.
bank_retrieval ── код: обязательный поиск по базе знаний Альфа-Банка (applications/knowledge_base)
   │              по запросам из разбора, с отсечкой по дате новости
impact_plan ── агент 2 (DeepSeek-V4.1-Flash): гипотезы влияния и план запросов
impact_research ── агент 2 сам вызывает инструменты (до 6 вызовов)
impact_write ── агент 2: итоговый анализ строго по схеме, у каждого пункта evidence
   │
validate ── код: существуют ли факты, поля профиля, вызовы T…, фрагменты аналитики;
   │         согласованы ли уровни; есть ли действия
critic ── агент 3 (GLM-5.3-Flash): точность, обоснованность, персонализация,
   │       противоречия, позиция банка
   ├── замечания critical/major → revise (агент 2 дорабатывает, до 2 кругов) → validate → critic
   └── ок или круги исчерпаны → finalize (если замечания остались — уверенность «низкая»)
```

Граф — LangGraph (`graph.py`), клиент к API моделей — свой (`llm.py`): строгий JSON по схеме, починка ответа при ошибке валидации, запасная модель при обрыве соединения, учёт стоимости.

### Инструменты аналитика влияния (`tools.py`)

Все инструменты привязаны к анализируемой компании — чужой профиль или платежи модель запросить не может.

| Инструмент | Что даёт |
|---|---|
| `get_company_section(section)` | раздел полного профиля: масштаб, отрасль, ВЭД, продукты банка, группа, контрагенты… |
| `get_counterparties(role, top_n)` | крупнейшие поставщики/покупатели по платежам с отраслью и долей |
| `find_counterparties_by_keywords(keywords, role)` | контрагенты из нужной отрасли и их доля в платежах |
| `get_company_card(company_id)` | карточка контрагента или компании группы |
| `get_group_companies()` | состав холдинга |
| `search_bank_analytics(query)` | дополнительный поиск по аналитике Альфа-Банка |

### Позиция банка

Гибрид: код всегда ищет по базе знаний (поиск BM25 из `scripts/knowledge_base/search.py`), агент может искать дополнительно. `bank_view` заполняется только из фрагмента аналитики или из цитаты аналитика Альфа-Банка в самой новости; если ничего по теме нет — `null`. У каждого риска и возможности указан тип источника: новость, профиль компании, аналитика банка, комментарий банка или вывод AI.

## Запуск

Нужны данные компаний в базе (`python manage.py import_data`) и ключ `LLM_API_KEY` в `.env`.

```bash
.venv/bin/python manage.py analyze_news --news applications/news_samples/yandex_dc_attack.json --company U_44564
.venv/bin/python manage.py analyze_news --cases applications/news_samples/cases.json --parallel 4
```

Новость — файл в формате RSS-парсера (`{generated_at, count, items}`); поле `content` с полным текстом необязательно. Результат — запись `AnalysisRun` в базе и файл `applications/analysis_runs/<news_id>__<company_id>.json`:

- `news_analysis`, `plan`, `impact` — результаты агентов;
- `critic_reports` — отчёты критика по кругам;
- `frontend` — данные в формате шаблонов `base/` (плюс источники выводов, действия, вопросы, уверенность);
- `trace` — все шаги: вызовы моделей (токены, стоимость, время), инструментов и проверок.

Из кода: `news_analysis.graph.run_analysis(news_dict, company_id)`.

Модели можно переопределить переменными `NEWS_ANALYST_MODEL`, `IMPACT_ANALYST_MODEL`, `CRITIC_MODEL`.

## Модели и почему

| Агент | Модель | Почему |
|---|---|---|
| Аналитик новости | Gemma 4 26B (запасная — DeepSeek-V4.1-Flash) | извлечение и классификация; самая дешёвая и быстрая; разбор кэшируется |
| Аналитик влияния | DeepSeek-V4.1-Flash (запасная — Qwen3.6) | самый быстрый и стабильный вызов инструментов среди рассуждающих моделей |
| Критик | GLM-5.3-Flash, `reasoning_effort=low` (запасная — Qwen3.6) | модель другой семьи, чем у аналитика; с полными рассуждениями на длинном входе провайдер рвёт соединение |

Kimi-K2.6 не используется: в ~10 раз дороже и медленнее при сопоставимом качестве.

## Проверка качества

Тестовые пары — `applications/news_samples/cases.json`: 6 новостей (3 реальные из RSS, в т.ч. 2 на английском и 2 только с анонсом; материал Forbes; пример из кейса) × 7 компаний разных отраслей, включая контрольные пары, где влияния быть не должно.

Последний прогон (13 пар): все без ошибок и без «низкой уверенности», доработок по замечаниям критика — 0–1, оценки критика 4–5 из 5. Одна новость даёт разный результат для разных компаний:

| Новость | Компания | Влияние (значимость) |
|---|---|---|
| Топливный кризис и ставка | розница топлива, Новосибирск | high (85) |
| | инфраструктурное строительство | low (45) |
| | разработчик ПО | low (30) |
| ЦБ сохранил ставку 14% | строительство с кредитами и лизингом | medium (55) |
| | импортёр продуктов с кредитами | medium (54) |
| | разработчик ПО без долга | low (22) |
| Рост предложения валюты, рубль | импортёр IT-оборудования | medium (58) |
| | импортёр рыбы | medium (50) |
| Атака на ЦОД «Яндекса» | оптовик компьютеров / разработчик ПО / строитель | low (28 / 30 / 22) |
| Медь (Bloomberg, только анонс) | производитель электроаппаратуры | low (30) |
| Завод Audi в США (Guardian) | розница топлива | none (12) |

Один анализ стоит 1,4–3 ед. API (`usage.cost`) и занимает 1,5–4 минуты; при `--parallel 4` 11 пар — около 5 минут.

Известные ограничения: поиск по аналитике банка — по словам (BM25), поэтому может найти не самый свежий документ; доли контрагентов — по платежам через банк, а у большинства контрагентов отрасль неизвестна; направление ВЭД и валюта расчётов в данных не указаны.

## Файлы

| Файл | Что внутри |
|---|---|
| `graph.py` | граф LangGraph и `run_analysis` |
| `agents.py` | три агента и обязательный поиск по аналитике |
| `prompts.py` | промпты (универсальные, без привязки к новости или отрасли) |
| `schemas.py` | Pydantic-схемы обмена между агентами |
| `tools.py` | инструменты аналитика влияния |
| `validation.py` | проверка ссылок и согласованности кодом |
| `bank_search.py` | обёртка над поиском по базе знаний |
| `article.py` | загрузка текста статьи по ссылке |
| `frontend.py` | перевод результата в формат шаблонов |
| `llm.py` | клиент API: строгий JSON, повторы, запасная модель, трассировка |
