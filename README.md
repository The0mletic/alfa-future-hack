# Новостная аналитика для Альфа-Бизнеса

Сервис для руководителей крупного бизнеса. Собирает новости, отбирает важные для конкретной компании и объясняет, как событие повлияет на её бизнес: риски, возможности, действия и позиция Альфа-Банка по его аналитике. У каждого вывода есть ссылка на источник.

## Запуск

Нужен ключ к API моделей хакатона. База `db.sqlite3` с данными кейса уже лежит в репозитории.

**Docker** (Compose v2.24+):

```bash
cp .env.example .env        # впишите LLM_API_KEY
docker compose up --build
```

**Без Docker** (Python 3.14):

```bash
python3.14 -m venv .venv
.venv/bin/pip install -r requirements.lock
cp .env.example .env        # впишите LLM_API_KEY
.venv/bin/python manage.py migrate
FEED_AUTO_REFRESH=0 .venv/bin/python manage.py runserver --noreload
```

Сервис откроется на http://localhost:8000.

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `LLM_API_KEY` | — | ключ API моделей, обязателен |
| `LLM_BASE_URL` | прокси хакатона | адрес OpenAI-совместимого API |
| `FEED_AUTO_REFRESH` | `1`, в Docker `0` | `0` — готовая лента при входе не пересобирается |
| `DB_PATH` | `db.sqlite3`, в Docker `/data/db.sqlite3` | путь к базе |
| `ALLOWED_HOSTS` | `localhost,127.0.0.1` | хосты Django |

Модели агентов можно переопределить переменными `NEWS_ANALYST_MODEL`, `IMPACT_ANALYST_MODEL`, `CRITIC_MODEL`, `RELEVANCE_MODEL`, `LLM_MODEL` (чат).

Пересборка данных с нуля:

```bash
python3 scripts/clean_data.py && python3 scripts/build_profiles.py   # профили из CSV кейса
.venv/bin/python manage.py import_data                                # компании и платежи в базу
.venv/bin/python manage.py fetch_news                                 # свежие новости из RSS
.venv/bin/python manage.py prepare_demo --company U_44564             # лента и анализ топ-3 заранее
```

`prepare_demo` занимает 10–20 минут и около 10 ₽ на компанию; при обрывах соединения у провайдера моделей отдельные анализы приходится повторять.

## Сценарий проверки

Вход — по ID компании, без пароля (заменяет вход в интернет-банк). Заранее подготовлена одна демо-компания — `U_44564` (опт компьютеров и ПО, Москва): лента собрана, у трёх главных новостей готов полный разбор (`/news/113/`, `/news/41/`, `/news/48/`).

1. Войдите как `U_44564`. Лента отсортирована по значимости новостей для этой компании (балл 0–100). Слева — профиль компании, по которому идёт подбор.
2. Откройте новость из топ-3. Там факты, «почему это важно компании», риски и возможности, позиция Альфа-Банка и источники. У каждого вывода указано, откуда он: новость, данные компании, аналитика банка или вывод AI.
3. Ниже — «Подробнее об анализе»: цепочки влияния и действия. В свёрнутой «Отладке» — все шаги агентов, вызовы инструментов и отчёты критика.
4. Задайте вопрос чату «AI-аналитик» справа: например, «Что нам делать?» или «Дайте первоисточник».
5. Откройте новость вне топ-3 и нажмите «Подготовить полный анализ». Через 2–4 минуты страница обновится.
6. Для любой другой компании рабочего набора (например, `U_102920`) лента соберётся в фоне при первом входе: 5–10 минут, пока идёт анализ, на карточках топ-3 значок «Готовим аналитику…».

Готовые разборы без запуска сервера: [applications/analysis_runs/html/index.html](applications/analysis_runs/html/index.html).

## Архитектура

```
RSS (feeds.txt) → парсер с полным текстом → база новостей
                                               │
вход по ID компании → сборка ленты в фоне ─────┤
   1. агент релевантности: новость × компания → каналы влияния → балл (считает код)
   2. полный анализ топ-3: аналитик новости → поиск по аналитике банка →
      аналитик влияния (план → инструменты → итог) → проверка кодом → критик → доработка
   3. чат: вопросы по новости, с инструментами и самопроверкой
```

| Модуль | Что делает |
|---|---|
| `base/` | интерфейс: вход, лента, страница новости, чат, фоновая сборка ленты |
| `relevance_agent/` | отбор и ранжирование новостей для компании ([README](relevance_agent/README.md)) |
| `news_analysis/` | разбор «новость × компания» тремя агентами ([README](news_analysis/README.md)) |
| `applications/chat_agent/` | чат «AI-аналитик» |
| `companies/`, `scripts/` | данные кейса: профили компаний, контрагенты, платежи |
| `applications/knowledge_base/` | аналитика Альфа-Банка из PDF, подготовленная для поиска ([README](applications/knowledge_base/README.md)) |

Стек: Django 5.2, SQLite, LangGraph. Модели из списка кейса: Gemma 4 (разбор новости), DeepSeek-V4.1-Flash (релевантность, анализ влияния, чат), GLM-5.3-Flash (критик), Qwen3.6 (запасная).

**Агентная логика.** Аналитик влияния сам составляет план: гипотезы и нужные данные. Затем он вызывает инструменты: профиль, контрагенты, группа компаний, поиск по аналитике. Все результаты сохраняются в общем состоянии и нумеруются, выводы ссылаются на них. Код проверяет, что ссылки существуют. Критик на модели другой семьи ищет ошибки и отправляет анализ на доработку, до двух кругов. Если замечания остались, уверенность помечается как низкая. Полная трассировка каждого прогона сохраняется в базе и видна на странице новости.

**Безопасность.** Компания берётся из сессии, поэтому чужие данные не запросить. Инструменты агентов только читают данные и ограничены анализируемой компанией и её контрагентами. Число вызовов ограничено, все вызовы журналируются. Загрузчик статей агента релевантности не ходит на внутренние адреса (у загрузчика анализа и парсера такой проверки пока нет). Ключи хранятся только в `.env`.

## Что не сделано и как бы доработали

- **Точка входа на главном экране Альфа-Бизнеса.** Макета главного экрана нет, прототип открывается сразу на ленте. Решение: виджет «Главное для бизнеса» с 1–3 срочными новостями и пункт в меню. Данные для него уже есть.
- **Внешний сервер.** Сервис не размещён. Образ готов: нужно задать `LLM_API_KEY` и `ALLOWED_HOSTS`, подключить диск к `/data`, вынести `SECRET_KEY` и `DEBUG` в окружение.
- **Вход.** Сейчас вход по ID без пароля и ролей. В продукте — SSO Альфа-Бизнеса с ролями.
- **Масштабирование.** Сейчас ленты собираются фоновыми потоками и хранятся в SQLite. Для нагрузки нужны очередь задач (Celery + Redis) и PostgreSQL. Новые отрасли и клиенты работают без изменения кода, новый источник новостей — строка в `feeds.txt`, новый PDF аналитики — через `scripts/knowledge_base`.
- **Качество на новых новостях.** Проверено на живом потоке RSS и тестовых парах, но размеченного экспертами набора нет. Решение: 100–200 пар «новость × компания» с оценкой эксперта и регулярный прогон.
- **Мониторинг.** Уже собираются оценки критика по пяти осям, доля прогонов с низкой уверенностью и с ошибками, стоимость и время. Не хватает отзывов пользователей: кнопок «полезно / неточно» и экспертной проверки выборки раз в неделю. Нет и дашборда с алертами.
- **Поиск по аналитике банка** — по словам (BM25). Семантический поиск точнее.
