# Запуск и демо-данные

Материал для README: требования, запуск, переменные окружения и данные для полного сценария.

## Требования

- Python 3.14 (`.python-version`), зависимости: `requirements.txt`, точные версии — `requirements.lock`.
- Или Docker с Compose v2.
- Ключ к API моделей хакатона: `LLM_API_KEY` в `.env` (шаблон — `.env.example`).

## Запуск в Docker (одна команда)

```bash
cp .env.example .env        # вписать LLM_API_KEY
docker compose up --build
```

Сервис: http://localhost:8000. При первом запуске база из репозитория (`db.sqlite3`) копируется в том
`app-data`, применяются миграции. Повторные запуски сохраняют базу.

## Запуск без Docker

```bash
python3.14 -m venv .venv
.venv/bin/pip install -r requirements.lock
cp .env.example .env        # вписать LLM_API_KEY
.venv/bin/python manage.py migrate
FEED_AUTO_REFRESH=0 .venv/bin/python manage.py runserver --noreload
```

`--noreload` обязателен: лента собирается в фоновых потоках, автоперезагрузка Django их обрывает.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `LLM_API_KEY` | — | ключ API моделей (обязателен) |
| `LLM_BASE_URL` | прокси хакатона | адрес OpenAI-совместимого API |
| `FEED_AUTO_REFRESH` | `1` (в Docker — `0`) | `0` — готовая лента при входе не пересобирается (демо) |
| `DB_PATH` | `db.sqlite3` в корне (в Docker — `/data/db.sqlite3`) | путь к базе |
| `ALLOWED_HOSTS` | `localhost,127.0.0.1` | хосты Django |

## Данные

В репозитории уже лежит готовая база `db.sqlite3` (≈40 МБ):

- компании рабочего набора (выручка от 10 млрд ₽), их контрагенты и платежи, профили для агентов;
- новости из RSS и заранее собранные ленты трёх демо-компаний с полным анализом топ-3 новостей.

Пересобрать с нуля:

```bash
python3 scripts/clean_data.py && python3 scripts/build_profiles.py   # профили из CSV кейса
.venv/bin/python manage.py import_data                                # компании и платежи в базу
.venv/bin/python manage.py fetch_news                                 # свежие новости из RSS
.venv/bin/python manage.py prepare_demo                               # ленты демо-компаний (~10 ₽ и 5–8 мин на компанию)
```

## Сквозной сценарий проверки

1. Открыть http://localhost:8000 → страница входа. Ввести ID демо-компании (см. ниже), пароль не нужен.
2. Лента «Главное для вашего бизнеса»: новости отсортированы по значимости для компании, у топ-3 есть полный разбор
   (счётчики рисков и возможностей, «Аналитика банка»), у остальных — «Краткая оценка».
3. Открыть новость из топ-3: факты, «почему важно компании», риски и возможности с горизонтом, позиция Альфа-Банка,
   источники; ниже — «Подробнее об анализе» (цепочки причин, действия, ограничения) и свёрнутая «Отладка: агенты и шаги».
4. Задать вопрос AI-аналитику в чате справа.
5. Открыть новость вне топ-3 → «Подготовить полный анализ»: появляется индикатор, через 2–4 минуты страница обновится.
6. Для новой компании (любой ID рабочего набора, например U_102920) лента собирается в фоне: прогресс сверху, на карточках
   топ-3 значок «Готовим аналитику…», пока анализ не готов (требует `FEED_AUTO_REFRESH=1` или первый вход компании).
