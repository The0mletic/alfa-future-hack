# Живые прогоны без аналитики банка — 26 октября 2026

## Получение новостей

Запущен реальный scripts/rss_full_parser.py на четырёх лентах из feeds.txt рядом с этим
отчётом, по 5 записей на ленту. Снимок: rss_full_report.json, generated_at
2026-10-26T11:34:39.159703+00:00 (14:34 МСК). Получено 20 новостей за 25–26 октября;
непустой извлечённый текст есть у 19. Одна страница Ведомостей не загрузилась.
Непустой текст сам по себе не доказывает полноту статьи. Тексты трёх выбранных новостей
просмотрены перед тестом; они содержат материал по заявленной теме.

Выбор задан до генерации, по разным темам: топливный рынок, валютный обзор, сервер для ИИ.
Это ручной тестовый набор, а не случайная выборка и не измерение общей точности модели.
Сохранены исходный RSS-отчёт и selected.json; новости не синтетические.

## Условия

Компания U_57706: оптовая торговля топливом, регион регистрации Москва.
Модель deepseek/deepseek-v4.1-flash, temperature=0, max_tokens=3000, до одного повтора.
Основная настройка модели в .env не менялась. Аналитика Альфа-Банка не читалась и
не передавалась. Полные тексты взяты из RSS-парсера, повторной загрузки в графе не было.
Каждая новость оценивается отдельно. Один экземпляр графа переиспользует справочники
контрагентов; первый запуск включает их начальную загрузку. Порядок прогонов: Трасса,
валютный обзор, сервер. Время ниже — полный вызов графа, без предварительного сбора RSS.

## Что обнаружили

- Модель различила слабую связь серверной новости (3) и отраслевую/финансовую связь (40/62).
- Валютный обзор оценён выше события в топливной отрасли: это предмет бизнес-калибровки,
  а не доказанная ошибка. Сейчас модель сильно опирается на эвристики sensitivities.
- В объяснении по Трассе модель обобщает проблему одной сети до стресса розничного сегмента,
  сравнивает выручку с разными/неуточнёнными периодами и использует регистрацию как аргумент
  географической связи. Эти выводы требуют оговорок; наличие поля не доказывает механизм.
- В валютном ответе отмечена неопределённость валют расчётов, но общий текст причины
  местами увереннее доказательств. Есть лишние связи через депозиты и лизинг.
- Первый ответ по серверу имел корректный JSON, но validate_exchange отверг его:
  «Нет подтверждённой связи или профиля контрагента». Второй ответ прошёл проверку.
- Ответы и профиль пока слишком объёмные для быстрого первого прохода. Вход первых
  двух запросов 9352 и 9763 токена; сокращение карточки и профиля ещё не реализовано.

Файлы *.result.json содержат полный результат и доказательства, *.calls.json — видимые
ответы модели, finish_reason, время и usage каждой попытки (не внутренние рассуждения).
Повторить прогоны можно скриптом relevance_agent.checks.run_fresh_news после выбора
нового места сохранения; существующий результат защищён от случайного повторного запуска.

Зависимости парсера установлены только в relevance_agent/.venv, список — requirements.txt
в этой папке. Опциональный newspaper3k не установлен: использовались trafilatura и bs4.
После установки 66 тестов прошли, pip check не обнаружил конфликтов. Основной код агента
в этой проверке не менялся.
