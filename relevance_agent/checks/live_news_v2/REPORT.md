1. **Порог шума.** Одна слабая длинная цепочка даёт 15–21 балл (weak 0.25 × подверженность
   1.0 × months 0.85 × medium 0.8). По мигрантам модель сама пишет «эффект почти нулевой»,
   но балл 17. Варианты: weak 0.25 → 0.15 или порог отбора (например ≥30).
2. **Ставка ЦБ = 50** при подверженности 1.0, выведенной только из наличия лизинга
   (размер долга неизвестен). Возможно, ключевой ставке тоже нужна скидка за догадку.
3. **Таймаут.** Один вызов из 20 упал по таймауту 60 с → not_scored. Можно разрешить
   один повтор именно при таймауте.
4. Весь прогон — одна компания. Персонализация (разные баллы для разных отраслей на тех же
   новостях) ещё не проверялась. Ручной разметки нет: «правильные» баллы не определены.
